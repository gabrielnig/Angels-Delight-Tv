## What you will do
Read what changed in each release of the admin area. Each release has the same four parts, so you can find what matters to you fast.

## Before you start
A new release note is added every time ARKDEV puts a new version of the site live. The newest release is first. A release note only lists changes you can see or use.

## Steps
1. Release 1.0, new: the Help centre, with guides, short silent videos with captions, a glossary and search from every screen.
2. Release 1.0, changed: nothing yet. Later releases list here any screen, button or word that moved or changed.
3. Release 1.0, fixed: nothing yet. Later releases list here any problem that was fixed and how to check it.
4. Release 1.0, what to do: nothing. Later releases say here if you need to change a setting or learn a new step.
5. To add a release, copy the four lines above and change the release name. Write each line in plain words.
6. Read the matching guide: each changed screen has a guide in the Help centre that was checked against the release. [Screen map](help:R03)

## What you should see
You can tell in under a minute whether a release changes something you do. Guides are re checked on every release, so the pictures and steps match the screen.

## If something goes wrong
- **A screen no longer matches a guide.** Tell ARKDEV the guide name and the screen. The guide is checked against every release, but a late change can slip through. [Status words](help:R06)
- **You cannot find a change.** Search the Help centre for the word you saw on the screen. [Screen map](help:R03)
