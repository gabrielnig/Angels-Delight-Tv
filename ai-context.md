## v2 conventions learned
- Storage inventory: every new cookie or browser storage key needs a row in `STORAGE_INVENTORY` (`apps/web/src/lib/consent/inventory.ts`). `inventory.test.ts` scans the source for declared names and fails until the row exists. `pnpm vitest run apps/web/src/lib/consent`.
- Performance: run `pnpm perf:budget` (optionally `--base URL /path`) after adding client code, images or fonts. Budgets live in `apps/web/src/lib/perf/budget.ts`.
- Messages: `messages-coverage.test.ts` only sees literal keys, so write `msg('a.b')` with a string literal (both branches of a ternary are counted, dynamic keys are not). Client copy lives in `packages/shared/src/messages/*-messages.ts`; new viewer copy in the linted component files fails CI.
- Tests: scoped only, `pnpm vitest run <file or folder>`. Integration files need `pg_ctlcluster 16 main start` and `TEST_DATABASE_ADMIN_URL=postgres://postgres:postgres@localhost:5432/postgres`; stop the cluster afterwards. Each lane note lists its own scoped command.
- Migrations: additive only, next free number on origin/main, renumber on a collision when rebasing and keep the journal `when` above the latest entry. Migrations 0039 and 0043 have no drizzle snapshot, so `meta/0040_snapshot.json` carries the sponsor tables. Every CHECK on a nullable column gets a NULL test (`LESSONS.md`).
- Decision numbers: take the highest `## D-` heading on origin/main plus one at merge time and renumber on conflict. Never renumber a number that already merged, citations exist; `scripts/decisions-ids.test.ts` fails on a new duplicate. Cite an old duplicate as `D-108 (M2)`.
- Viewer API validation errors are 422 with `fields` (`ValidationFailed`), not 400. Auth is 401, forbidden 403, missing 404, conflict 409, rate limit 429.
- Admin has two implementations, fixtures in `apps/web/src/lib/data/admin` and real in `packages/catalog/src/admin`. Parity tests (`home-parity.test.ts` and others) fail when they drift.
- Doc sync guards: `scripts/design-doc-sync.test.ts`, `l10-doc-sync.test.ts`, `monetization-doc-sync.test.ts`, `user-stories-sync.test.ts`. Change stories, modules or tokens and these tell you what else to edit.
- Helper scripts and mockups that live under `/home/claude` (the lane brief, `/home/claude/ad/project/S*.dc.html`, worktrees under `/home/claude/wt2`) are not in the repo. Code, tests and docs must not depend on them.
- Shell cannot write inside `.claude/`, so the design skill reference is mirrored by the owner (see the checklist in `docs/RELEASE-CANDIDATE.md`).

Apps: `@ad/web` (viewer site, `/admin`, `/api/*`, `/watch/[videoId]`, PWA with service worker, `/api/health`, `/api/ready`), `@ad/worker` (pg-boss consumers for every video queue, nightly analytics rollup, monthly view event and audit prune), `apps/whisper` (Python faster-whisper service, `WHISPER_FAKE` for dev), `apps/edge` (Cloudflare Worker for signed segment URLs).
Packages: `db` (schema, migrations, RLS, `withAccount`), `config`, `shared`, `storage` (local and S3), `ui` (tokens and component library), `auth` (Argon2id, sessions, per account keys, staff TOTP, invites, viewer two step, Google sign in), `security` (rate limiter, lockouts, CSRF, CSP, IP handling), `mailer`, `audit`, `analytics`, `queue`, `video` (upload, encode, captions, markers, previews, playback authorization, purge), `catalog`, `viewer`, `player`, `theme`, `i18n` (translation store and service), `payments` (Paystack, donations), `sponsors`, `launch` (apply, dns check, secrets). Layout and import rules: `docs/ARCHITECTURE.md` section 4.
Data modes: `VIEWER_FIXTURES=on`, `AUTH_FIXTURES=on`, `ADMIN_DATA=fixture` give fixtures outside production. Production always uses real services. Seeds: `pnpm db:seed:admin`, `pnpm db:seed:demo`.
Run scoped tests only: `pnpm vitest run <path>`. Integration tests (`*.int.test.ts`) need `TEST_DATABASE_ADMIN_URL` (see `docs/DEV-SETUP.md` section 5). Install the hook once with `pnpm hooks:install`. Quality findings and the repeatable sweep: `docs/QUALITY-REVIEW.md`.
