2. Where the label comes from
Same group: Next: L6 (item short code plus number).
Next lesson starts a new group: Next: P2 L1 (group code and item code), so Lesson 1 is not confused with the old Lesson 1.
Series with its own names: that series code is used, for example Next: C12.
Longest case: three letter code and three digit number, for example Next: LES124. The chip truncates with an ellipsis, never wraps, and the full words stay in the accessible name.
Screen reader name: Genesis for beginners, Part 2, Lesson 6 is next, Next: L6.
