State 6 · Copy rules for empty and error states (gate test reads the shared copy constants)

Copy rules

RuleDetail
Sentence case, plain wordsEveryday English for a Nigerian audience. No jargon.
One sentence of helpUnder 20 words. Errors may use two: what happened, what to do.
One actionVerb first label: Browse videos, Try again, Back to Home.
No blameNot "You entered". Say "That code is not right."
No dashes, no exclamation marks, no emojisUse a full stop or a comma.
Reference in caption onlySmall muted text under the action.
Findings. The existing S33 server error mockup has two actions (Try again and Back to Home) and S20 uses "Tap My List on any video" where DS 11.20 says "Tap the plus on any video to save it for later." Both differ from the one action rule and the copy source. The pattern above follows the rules, the older mockups need a copy pass when their lanes are built.
