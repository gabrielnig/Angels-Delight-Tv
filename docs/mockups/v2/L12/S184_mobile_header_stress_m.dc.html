Mobile header width stress test at 320, 360 and 414

Header B with real Yoruba, Igbo and Hausa draft labels and longer illustrative ones. Every case is measured in the DOM: no horizontal overflow, no overlapping controls, no wrapped control label, every control at least 44 px.

Measured in Chrome with Inter (Space Grotesk falls back to Inter here, which is wider, so this is conservative)
