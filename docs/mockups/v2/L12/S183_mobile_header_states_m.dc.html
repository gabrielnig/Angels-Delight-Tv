BrandMark 32 px plus name. Name has min-width 0 and an ellipsis. Under 340 px the name hides and the link keeps its aria-label. Kids: mark and Kids badge.
Scrim (changed)New token --nav-scrim-fade (--space-4). The gradient layer reaches that far below the bar and holds 0.85 to the bar bottom. Replaces --nav-scrim-hold 70 percent, which breaks under an inset.
