Frame 4: the rule
Written into DESIGN-SYSTEM 11.16. Header and cells of one column always share a class.
Column contentHeader and cellsClass
Counts, sizes, durations, percentages, days left, rows, usesRight, tabular numeralsadm-num
Text, titles, names, emails, dates, times, identifiersLeftnone
Status badges and short tagsLeftnone
Yes or No marks and icon only booleansCentreadm-ctr
Row actions (header is screen reader only)Right, buttons right alignedadm-actions
States: hover, focus and empty
Hover uses the primary tint. Focus is the 3px ring. The empty table keeps 16px around the message inside the card.
