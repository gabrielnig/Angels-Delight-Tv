Skip intro, steady

0:21 / 5:52
Button sits bottom right above the seek bar. The S key hint shows on desktop only.
Must

How it behaves

  • Shows when playback enters the intro window set in the admin (or when resume lands inside it) and fades in with opacity only, 200 ms.
  • Label is the action: Skip intro. Tap, click, Enter or the S key all do the same thing.
  • Result seeks to the end of the window, keeps playing, and moves focus to the Play button.
  • First in Tab order after the video, before the control bar, so keyboard users reach it at once.
  • Announced once per window through the polite live region: "Skip intro available. Press S."
  • Contrast ink on white is 17:1. Focus ring is the yellow player ring, 3 px.
