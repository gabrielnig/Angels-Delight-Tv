## Paystack facts verified on 2026-11-24 (plan [VERIFY] items)
Sources: paystack.com/docs/payments/webhooks, paystack.com/docs/api/transaction, support.paystack.com (transaction charges, USD).
- Webhook signature: header `x-paystack-signature`, HMAC SHA512 of the raw body keyed with the secret key. Confirmed. Respond 200. Retries: live mode every 3 minutes for 4 tries then hourly for 72 hours, test mode hourly for 72 hours. The docs page does not list source IPs, so the code never relies on IPs.
- Events documented: `charge.success`, `charge.dispute.create|remind|resolve`, `refund.pending|processing|processed|failed`, `subscription.create|disable|not_renew|expiring_cards`, `invoice.create|update|payment_failed`, plus transfer and other events we ignore. There is NO documented `charge.failed` event: the plan's failed handling must come from verify and the reconcile job (the processor still accepts a `charge.failed` body if one ever arrives). Payloads carry no event id, so the event key is a sha256 of event, reference and paid_at.
- Initialize: `POST /transaction/initialize` takes `amount` in the currency subunit (kobo, cents), `email`, optional `currency`, `reference`, `callback_url`, `metadata` as a stringified JSON object. Reference may contain only letters, digits, `-`, `.` and `=`. The plan's `ad_don_` reference has underscores and is NOT valid: references are `ad-don-` plus 20 letters and digits. Response gives `authorization_url`, `access_code`, `reference`.
- Verify: `GET /transaction/verify/:reference`, status values `success`, `failed`, `abandoned` (anything else is treated as pending).
- Fees (Nigeria): local 1.5 percent plus NGN 100, the NGN 100 is waived under NGN 2,500, local fees capped at NGN 2,000. International cards 3.9 percent plus NGN 100 (Amex 4.5 percent). A fee is not shown to donors unless `donate.cover_fees_option` is on.
- Minimum transaction: no minimum was found in the pages read. Our own minimum stays `donate.min_minor.ngn` (NGN 200) and is a setting.
- USD: the business requests international payments in the Dashboard (answer within 48 working hours), holds a Zenith Bank USD domiciliary account, adds it under Settings, Accounts, and Paystack confirms within 24 hours. Until then `donate.usd.enabled` stays off. Recurring plans and subscriptions on the account were not verified here and need a check in the Paystack dashboard before monthly giving is switched on.
